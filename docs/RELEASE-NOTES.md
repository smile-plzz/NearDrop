# NearDrop 1.0.0

First portable Windows release: original-byte local file transfer, laptop/phone browser dashboard, one-use QR pairing, multi-file queues, chunk retry/resume, shared text and links, file search, persistent history, SHA-256, authenticated download ranges, device revocation, and owner deletion controls.

Windows 10/11 x64. Extract the full ZIP and run NearDrop.exe. No Python installation required. Phone requires a modern browser on the same trusted Wi-Fi.

This is a local HTTP utility: network traffic is not encrypted. All paired devices share the same room. Keep the phone foregrounded for large uploads. Native Windows/iPhone hardware acceptance testing remains outstanding; see VALIDATION.md.
